# 1 из 22 миллионов

Симуляция взросления о цифровой безопасности по образцу «1 из 8 миллиардов». Это разминка перед рабочими листами «Мастерской безопасных решений» для молодых педагогов.

**Играть:** https://irinilou.github.io/1in22m.life/

Случай выбирает один из 89 регионов России (с вероятностью по реальному числу учащихся), город или село, семью, достаток, бабушку и четырёх ровесников. Жизнь идёт сама — с первого класса до 23 лет. Есть пауза, скорость 1×–8× и кнопка «До следующего решения». По ходу жизни всплывают решения о паролях, ссылках, играх, картах, звонках «из банка», «подработке», фото и геометках — около 20 за жизнь. Последствия часто приходят через годы. Травля появляется как результат цифровых решений, а не отдельной темой.

- Миры: прошлое (рождение в 1990–1994, интернет приходит в школьные годы), сегодня (2008–2012), будущее (2018–2022, ИИ и голосовые клоны).
- Путь: школа, после 9 класса — 10 класс или колледж, после 11 — колледж, после диплома — работа.
- Шкалы: защищённость, счастье, знания, отношения, доверие к взрослым. Доверие решает, расскажет ли герой взрослым, когда что-то случится.
- Финал «Запись о жизни»: решения, взломы, случаи травли, потерянные деньги, карта жизни, «Взгляд педагога».

## Данные

Число школьников и студентов колледжей по регионам: Росстат, «Регионы России. Социально-экономические показатели. 2025», табл. 5.3, 5.8, 5.10 (начало 2024/25 учебного года). По ДНР, ЛНР, Запорожской и Херсонской областям в сборнике нет данных — использованы оценки (см. `js/regions.js`). Факты в блоках «Данные» — с источниками в `js/world.js`.

## Как поправить

```
index.html          разметка
css/style.css       оформление (цвета — в начале файла)
js/world.js         эпохи, имена, профессии, фокусы года, ровесники, факты
js/events.js        все решения, последствия, фоновые события и ежегодные риски
js/regions.js       89 регионов: население, школьники, студенты СПО
js/engine.js        движок: время, планирование событий, интерфейс
tools/make_doc.py   собирает Word-файл со всеми событиями из этих же файлов
```

Тексты событий — строгий JSON (двойные кавычки, без запятой в конце списка). Род героя: `дал{|а}`, `{доволен|довольна}`. Описание полей — в начале `js/events.js`.

Word-файл со всеми ветками: `python tools/make_doc.py` (нужен `pip install python-docx`). Он не попадает в репозиторий, чтобы участники не видели заранее все последствия.
