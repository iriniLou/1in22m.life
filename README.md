# 1 из 22 миллионов

Онлайн-игра на 5–7 минут с телефона: разминка перед рабочими листами «Мастерской безопасных решений» для молодых педагогов.

**Играть:** https://irinilou.github.io/1in22m.life/

По мотивам «1 из 8 миллиардов». Случай выбирает один из 89 регионов России, населённый пункт, год, имя, класс или курс колледжа и историю. Участник выбирает время (прошлое 2004–2010, настоящее 2025–2026, ближайшее будущее 2031–2036) и уклон жизни героя (учёба, друзья, творчество, спорт, игры и техника), а потом дважды принимает решение в ситуации, связанной с кибербуллингом. В финале — что стало с героем через 8–14 лет и «взгляд педагога».

- 30 историй: по 10 на каждое время, у каждой два выбора по три варианта и поворот между ними.
- 6 историй — «разминки»: они перекликаются с популярными кейсами рабочих листов, но в другом времени и с другой стороны.
- Без тяжёлых сцен. Правильных ответов нет: у каждого варианта есть плюсы и цена.
- Если зал оставляет время «Как повезёт», при 350 участниках одна история в среднем выпадает около 12 раз, а самая частая — около 20.

## Как поправить тексты

```
index.html               разметка
css/style.css            оформление (цвета эпох — в начале файла)
js/content.js            эпохи, имена, уклоны жизни, профессии в финале
js/stories-past.js       истории о прошлом
js/stories-present.js    истории о настоящем
js/stories-future.js     истории о будущем
js/stories-echo.js       истории-«разминки» по мотивам кейсов рабочих листов
js/regions.js            89 субъектов РФ: название, «где», центр, население
js/app.js                движок игры
tools/make_doc.py        собирает Word-файл со всеми ветками из этих же файлов
```

Род пишется так: `пош{ёл|ла}`, `сделал{|а}`, `{друг|подруга}` (сначала форма для героя, потом для героини). Подстановки — `{name}`, `{friend}`, `{mentor}` и другие (список — в начале `js/stories-past.js`). Файлы историй — строгий JSON: двойные кавычки, без запятой после последнего элемента.

Проверить конкретную историю: добавьте к адресу `?story=` и её id, например `?story=n-geo`.

Word-файл со всеми ветками: `python tools/make_doc.py` (нужен `pip install python-docx`). Файл в репозиторий не попадает, чтобы участники не видели заранее все концовки.
